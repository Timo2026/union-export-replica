# 十日谈 · 把一封 CNC 询盘，变成可审计的商业决策

> 我们不是又一个聊天 Agent。
> **LLM 提议，确定性引擎裁决价格，Skills 管窄触发与业务能力，DGX Spark + Nemotron 提供本地算力。**
> 十天里，我们把这句话从口号变成了可复现、可验证的证据。

---

## 引子 · 一句话定位

NVIDIA DGX Spark 黑客松 · Agent Skills 开发挑战赛，赛题要求四件事同时压中：**一个 Agent 应用、一套 Skills 工艺、跑在 DGX Spark 上、落在真实行业里产生可验证价值**。

我们选的是一个最不"性感"、最难糊弄的切口——**制造业的询报价（RFQ）**。一个客户发来一封邮件、一张图纸，我们要在几十秒内给出：看懂图纸、抽取规格、判断可制造性（DFM）、算出价格、生成一封**只能作为草稿、绝不自动发送**的回复。而这条链上最关键的一条铁律是：

> **LLM 永远不定价。** 所有最终价格、DFM 冲突、裁决，唯一权威是确定性引擎 **Timo**（`:7862`，sha256 锁定）。大模型只"提议"，引擎才"裁决"。

这句话是后面所有故事的根。

---

## Day 0 · 定向：不做"更聪明的聊天机器人"

开赛前我们把十几个历史目录推到一边，只保留一个提交主体。判断很残酷：讲故事只能拿一半分，包装 Skills 也只能拿一半分。四件事必须同时命中，否则杠杆不够长。

定位一句话：**填补"垂直行业里可验证商业价值"的空白**——Omarchy/NVIDIA/Skills 解决了"Agent 住进系统、用好硬件"，但没人解决"Agent 做成可验证的生意"。

学到的第一件事：**战略不是选最强叙事，是选得分杠杆最长的那条。** 后来 SSH 连通的事实直接废掉了"平台分拿不到"的反方论据——再次证明"先连上"比"先论证"值钱。

---

## Day 1 · 摸底：6.0 不是 8.5

我们跑 brutal 自检，`PROJECT-SUMMARY` 一锤定音：实测综合 6.0–6.5，不是声称的 8.5。四颗 P0 钉子被实测钉死：缓存共享可变状态被污染、静态资源 404、版本三套不一致、Schema 校验形同虚设。

学到的一条纪律后来救了很多次：**凡涉及缓存/单例/可变状态，必须实跑，不能"读代码推理"。** 把"文件存在"当成"断言通过"是自欺。

---

## Day 3 · 全栈：Nemotron 替掉 LMStudio

DGX Spark 的 GPU 全栈跑通后，方案重写——不是切一条链路碰瓷，是**配置级全量平替**。我们选了 Nemotron 家族，理由三条：

- **全 NVIDIA 自研**：评委问"全栈深度"，答得最硬。
- **MoE 能效梯度**：30B 总参只激活 3B，单卡扛得住。
- **Omni 三合一**：一个服务顶替 VLM + ASR + OCR 三个，绕开 Parakeet 在 Blackwell 上的限制。

铁律同步立死：**DETERMINISTIC 永不平替。** 无论 LLM 换什么后端，价格永远由 Timo 裁决。

学到：**接口兼容 ≠ 行为等价。** 切模型不算数，得跑等价回归——引擎价格的 sha256 跨后端 byte-identical，才算平替成功。

---

## Day 5 · 负向：不触发，比触发更难

评委最狠的一问浮出来：**"会不会对无关输入也乱触发业务 skill？"** 全仓搜 negative trigger——0 命中。33 个 SKILL.md 全讲"什么时候该动"，没有一个讲"什么时候不该动"。

这其实是 Skills 工程深度的真正分水岭。一个会聊天也会报价的 Agent 不值钱；一个**该报价时报价、不该报价时纹丝不动**的 Agent 才值钱。我们给核心技能补了禁止条件、误触发后果、负向测试。

学到：**克制比能力更贵。** Negative trigger 是 Skill 的"不作为"契约，和铁律①的"不越界"契约是一对：一个管"该做不做"，一个管"不该做却做"。

---

## Day 7 · 等价：sha256 对上的那一刻

同一个黄金样例，local runtime 跑一遍、Nemotron 全栈跑一遍，比对引擎价格的 sha256。**结果一致。** 那一刻 NVIDIA 全栈才算真的平替成功——不是"接上了"，是"接上了且生意没变"。LLM 抽取字段允许统计差异（写进报告），但引擎价格必须 byte-identical。

学到：**"接上了"和"等价了"，差一个 sha256。** 这是"换了后端生意还在不在"的唯一答案，也是 NVIDIA 全栈的终极证据。

---

## Day 8 · 闭环：A/B 不是单测

复用早躺在 `evaluation/metrics.py` 里八个月、从没人调用过的 `ab_report`：A=完整 skills + 引擎，B=去掉关键 skills（或纯正则抽取）。差异出来，一句话连到"可验证商业价值"：

> 去掉 Skills 之后，字段准确率掉 X 个点、HITL/BLOCKED 拦截率掉 Y 个点——**Skills 不是装饰。**

学到：**函数存在不等于能力存在。** 调用一次、留下产物，它才从死代码变成得分。交付的定义不是"代码里有"，是"跑过且留了产物"。

---

## Day 10 · 交付：指给评委看

按答辩三刀走：**①价格谁生成？** 指 Timo 引擎，现场比对 sha256；**②和普通 Skill 包有何不同？** 指 negative-trigger 矩阵 + A/B JSON + 行业闭环 + 审计链 + HITL；**③在哪跑的 Spark？** 指节点实测 + Nemotron 全栈冒烟 + 行为等价。

学到：**答辩不是讲功能，是答质疑。** 把评委最狠的三刀预先想透、留好证据、对得上口径，比 PPT 漂亮重要十倍。

---

## NVIDIA 全栈 × 本项目：融合点在哪

这不是"调用一个大模型"，而是把 NVIDIA 从硬件到推理到模型优化的整条栈，焊接进一条确定性询报价流水线：

| NVIDIA 全栈层 | 在本项目中的角色 |
|---------------|------------------|
| **GB10**（Grace-Blackwell，Arm CPU + ≈128GB 统一内存） | 多模态大模型 + 向量检索 + CAD 几何 + 确定性计价**同驻一机，数据不出本机** |
| **CUDA 13.0 / 驱动 580.82.09 / DGX OS 7.2.3** | NVFP4 内核与 FlashInfer JIT 的运行底座 |
| **vLLM 多实例** | 并发承载 Omni 多模态 / Embedding / 轻量辅助三类服务 |
| **Nemotron-Omni-30B-A3B（NVFP4）** | any-to-any 统一端点：**图纸视觉 + 询盘语言 + 语音 ASR** 一次接入 |
| **Nemotron-Embed-1B（NVFP4）** | 询盘/物料知识检索（RAG）的语义向量 |
| **推理优化**（NVFP4 / 显存调优 / 投机解码 / reasoning-parser） | 沉淀为可复用 Agent Skills，反向压低智能体时延与显存 |
| **NeMo Guardrails** | 询盘请求的软护栏（越界/敏感分流） |
| **OpenClaw + Agent Skills 编排** | 把各层编排成"图纸→DFM→报价→草稿"闭环 |

一个真实的闭环（6061 铝制卡片阅读器外壳，全流程在 GB10 本地完成）：一张含公差的工程图纸 → Omni 视觉抽规格 → Embed 召回材料/表面处理知识 → `step-factory`（CAD 生成 350+ 实体）→ `dfam-check` → 确定性引擎出价 → **egress DENY、仅草稿不发送**。

## 真实状态（节点实测）

> 以下数字取自 `docs/REAL_STATE.md`，均为近似值，不同取数窗口会有波动。

- GPU 利用率 **≈96%**、显存 **≈74GB**、统一内存 **≈121GiB**（可用即 128GB 级）。
- 主端点吞吐 **数百 tokens/s 量级**（≈450），黄金链端到端 **30–90s**。
- 业务技能 **33 个**（`app/skills/`）；OpenClaw 磁盘技能 **51 个**，平台实时登记 **47 项**（其中 **11 个完全可用**）。
- 关于**阶跃星辰 StepFun**：如数说明——它只作为**回落位（fallback）**，data-stays-local 下不主动出网；本地 NVFP4 Nemotron 是唯一主力。

## 收口：700+ 全绿 + 一把秘密锁

修复四颗 P0 钉子后 `pytest` 跑到 **700+ passed / 0 failed**（728 为早期时点，详见长卷勘误），版本四处统一。出包前 grep 密码/密钥模式零命中；登录表、`.env`、mailbox、`STEPFUN_API_KEY`、节点公网 IP / JupyterLab token 全部**不入库**——用一个可复现脚本 `scripts/verify_replica.sh` 把"无秘密、有端口、结构齐"固化成断言。

学到：**完整性不是功能多，是口径一致。** README badge == git tag == CHANGELOG == health 返回值，四处对得上，比多一个功能值钱。可信度是底座。

3. **函数存在不等于能力存在**——调用过、留了产物，才算交付。
