## 何时触发

**正向触发：**
- DFM / Design for Manufacturing / 可制造性设计
- 面向制造的设计 / 工艺性审查
- 3D打印可行性 / 零件可制造性
- 设计优化 / 减材约束 / 增材约束
- 壁厚检查 / 逃逸孔 / 支撑设计

**禁止调用：**
- 纯美学外观设计（非制造约束相关）
- 电子电路DFM（非机械零件）

## 输入规范

| 参数 | 必填 | 类型 | 说明 | 示例 |
|------|------|------|------|------|
| process | 是 | string | 制造工艺 | SLM/CNC/钣金 |
| part_feature | 是 | string | 零件特征描述 | 薄壁件/深腔/内孔 |
| critical_dim | 否 | number | 关键尺寸 | 0.5mm壁厚 |

## 输出规范

```
📐 DFM审查
─────────────────
制造工艺: <SLM/CNC/钣金>
关键约束:
  最小壁厚: <mm>
  最大深宽比: <比值>
  最小孔径: <mm>
  逃生孔要求: <是/否>
优化建议: <具体修改方案>
可制造性评估: <可行/需修改/不建议>
```

## 执行流程

1. 确认制造工艺类型
2. 检索对应工艺的DFM约束规则
3. 对比零件特征与约束
4. 给出修改建议

## 边界约束

- 能做：标准DFM规范检查、3D打印可行性评估
- 不能做：复杂装配体全局DFM（需STEP模型）、FEA力学分析
- 已知限制：基于择幂DFM流程，其他厂商规范可能不同
