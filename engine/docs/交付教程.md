# 第一部分：功能介绍

## 1.1 系统概述

**Union·由你 CNC AI 工艺大脑** 是一个 AI 驱动的 CNC 加工智能报价与工艺规划系统。上传图纸或描述零件需求，系统自动完成从图纸解析到报价输出的全链路处理。

### 核心设计哲学

```
离线优先 · 多模型自适应 · 规则引擎兜底 —— 断网也能跑
```

### 一句话能力

```
一句话画图 → 3D预览 → 上传报价 → 一键输出打包
```

### 1.3.3 报价公式（白盒透明）

```
─── 成本计算（按材料分档，基于杰沃509条数据校准）───

材料费 = MAT_PRICE_PER_KG[材料] × weight_kg × 工艺系数 × 公差系数 × 粗糙系数
加工费 = 15 × MAT_FIXED_COEF[材料] × 工艺系数 × 公差系数 × 粗糙系数
表面费 = (SURF_FIXED_FEE[表面] + SURF_AREA_RATE[表面] × 面积dm²) × 数量

─── 价格组装 ───

基础费 base = 15 + 60 × weight_kg × (mat_price / 22)
单价 unit = base × 工艺系数 × 公差系数 × 粗糙系数 + 表面费 + 螺纹费
总价 total = unit × quantity × 批量折扣
最终价 final = total × (1 + 利润率)

─── 批量折扣 ───

≥100件 → ×0.7
≥50件  → ×0.8
≥20件  → ×0.9
<20件  → ×1.0
```

### 1.3.4 公差与粗糙度系数

| 公差等级 | 系数 | 粗糙度Ra | 系数 |
|----------|------|----------|------|
| 精细 | 1.30 | Ra0.2（镜面） | 1.80 |
| 中等 | 1.00 | Ra0.4（超精） | 1.60 |
| 粗糙 | 0.85 | Ra0.8（精密） | 1.40 |
| — | — | Ra1.6（标准） | 1.15 |
| — | — | Ra3.2（半精） | 1.00 |

### 1.3.5 工艺不兼容黑名单（DFM冲突检测）

系统内置 36 条材料×表面处理不兼容规则，例如：
- 铝合金 + 发黑 → ❌（发黑是钢铁氧化层工艺）
- 不锈钢 + 镀锌 → ❌（不锈钢本身耐腐蚀）
- 钛合金 + 镀铬 → ❌（钛合金不做镀铬）
- 45钢 + 阳极氧化 → ❌（阳极氧化为铝/钛工艺）

## 1.4 DFM 可制造性审核

DFM（Design for Manufacturing）审核对每个零件检查以下维度：

| 检查项 | 阈值 | 判定 |
|--------|------|------|
| 薄壁 | 壁厚 < 0.8mm | WARN |
| 细长比 | L/D > 25 | WARN |
| 深孔 | L/D > 8 且 min_dim < 8mm | WARN |
| 材料缺失 | 材料未识别 | WARN |
| 重量缺失 | 重量为0 | WARN |
| 工艺不兼容 | 材料×表面处理命中黑名单 | FAIL |

**改进后审核结果**（521零件）：PASS 387(74.3%) / WARN 130(25.0%) / FAIL 4(0.8%)

## 2.2 安装部署

### 方式 A：conda 环境（推荐，支持 STEP 精确解析）

```bash
# 1. 克隆仓库
git clone https://github.com/timocao/CNC-AI-Brain.git cnc-ai-brain
cd cnc-ai-brain

# 2. 创建 conda 环境（含 OCP + cadquery + trimesh + cascadion）
conda env create -f environment.yml
conda activate step-render

# 3. 配置环境变量（可选）
cp .env.example .env
# 编辑 .env 填入 API Key（无 key 则降级规则引擎，仍可报价）
```

### 方式 B：venv 虚拟环境（精简，仅规则引擎报价）

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux
set PYTHONUTF8=1                # Windows 避免 GBK 编码
pip install -r requirements.txt
```

### 方式 C：Docker 部署

```bash
cp .env.example .env
docker-compose up -d --build
```

### 步骤 3：解析 STEP 文件

```python
# task3_parse_step.py
# 输入：590个 .step 文件
# 输出：parts_unified.csv（521行，合并PDF+STEP数据）
# 功能：
#   - extract_bbox_from_step() 提取包围盒（X/Y/Z尺寸）
#   - estimate_volume_from_bbox() 估算体积
#   - get_material_density() 获取材料密度
#   - 重量 = 体积 × 密度（自动补算缺失重量）
```

### 步骤 4：计算报价

```python
# task4_calc_quote.py
# 输入：parts_unified.csv（521行）

    max_dim_mm=100,        # 最大尺寸(mm)
    tolerance="中等",       # 公差等级
    roughness_ra=1.6,      # 粗糙度Ra
```

## 4.3 批量报价执行推理

### 推理步骤 1：数据解析推理

```
ZIP包 → 递归解压 → 识别 tech-details.pdf + .step 文件
                    │
                    ├── PDF: OCR提取文本 → 正则匹配材料/数量/表面/公差
                    │        → MATERIAL_MAP 归一化（60+别名→12+标准Key）
                    │
                    └── STEP: cadquery解析 → 包围盒(X,Y,Z) → 体积估算
                              → 重量 = 体积 × 密度（缺失时自动补算）
```

### 推理步骤 2：报价计算推理

```
对每个零件：
  1. 材料识别 → MAT_COEFS / MAT_PRICE_PER_KG 查表
  2. 尺寸分析 → 大件/中件/小件分档定价
  3. 工艺判定 → 工艺系数（三轴1.0/四轴1.3/五轴1.8）
  4. 公差系数 → TOL_COEF[精细1.30/中等1.0/粗糙0.85]
  5. 粗糙系数 → ROUGH_COEF[Ra0.2=1.80 ... Ra3.2=1.0]
  6. 表面费用 → 固定费 + 面积费率×面积
  7. 螺纹附加 → 螺纹孔数 × 5元/孔
  8. 批量折扣 → 数量≥100→0.7 / ≥50→0.8 / ≥20→0.9
  9. 利润加成 → × (1 + 利润率)
  10. 输出 → 单价/总价/最终价/交期/费用明细
```

### 推理步骤 3：质量验证推理

```
报价结果 → 置信度评估（材料/重量/尺寸/公差完整性打分）
         → DFM审核（薄壁/细长/深孔/工艺不兼容）
         → Bug检测（单价异常/缺失字段/逻辑矛盾）
         → A/B测试（体积修正前后对比）
         → 消融实验（各模块贡献率）
```
