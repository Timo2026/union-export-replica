## 判断规则
### 领域判断
- 涉及择幂科技/Xometry/北京怀特瑞拉、报价、画图、Sales Ops、CRM、周报、Matt、英文沟通 → work
- 涉及垣钧、孩子、爱人、幼儿园、二胎三胎、亲子、家庭、哭了、打架、赖床、不想去 → family
- 其他 → general

### 类型判断（work）— 精确匹配
- 周报/汇报/管理层摘要/Executive Summary/GM汇报/向上汇报 → report（不落到daily_digest！）
- 录音文本/访谈记录/客户拜访/会议记录/Meetings notes/总结会议 → meeting_minutes
- 复杂问题/行业分析/流程设计/方法论/SOP/比较/深度问题/系统设计 → deep_research
- 短问题/怎么回/怎么说/话术/标题/文件名/简单问题 → quick_qa
- 人物推演/项目推演/组织变动/策略推演/沙盘/What if → sandbox
- 允许发散/可行动/仅观察/头脑风暴/创意 → brainstorm
- 以上都不匹配时才考虑 → daily_digest（日常记录/观察/风险/明日动作）

### 类型判断（family）
- 学习/课外课/老师/幼儿园 → family_education
- 情绪/行为/亲子冲突 → family_emotional
- 爱人/夫妻关系/二胎三胎 → family_planning
- 健康/法律/财务 → family_health

### 信号检测
- 情绪上头/想强推/想说服/想控制 → control_urge: true
- 过度猜疑/否定一切/犬儒倾向 → cynical_drift: true
- 想牺牲健康/家庭/底线换结果 → sacrifice_signal: true
- 明显情绪化/发散/过度猜测 → emotional_risk: true
