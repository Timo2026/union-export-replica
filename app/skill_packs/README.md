# Skill Packs (L2 Module Packs)

从外部 skill 包适配的能力，**默认提案/证据**，不覆盖 Timo 终价。

| Pack | Skills | iron_rule |
|------|--------|-----------|
| quote-pack | unionskill-quote-bridge, reference-quote-bridge | llm_proposal |
| decision-pack | ceo-decision-cb-bridge, reid-os-bridge | llm_proposal |
| knowledge-router | knowledge-index-lookup | deterministic (lookup only) |

启用状态见 `config/skill_registry.yaml`。catalog_only / quarantined 不在此出现。
